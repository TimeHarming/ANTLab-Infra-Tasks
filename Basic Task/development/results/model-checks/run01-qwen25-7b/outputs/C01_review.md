## 2. 检查方法

| 判定 | 含义 |
| --- | --- |
| ✅ 命中 | 正确指出源码缺陷（触发条件、当前行为、影响均与源码一致） |
| ❌ 相反 | 声称"已实现正确处理"，但源码实际会崩溃或行为与约定不符 |
| ⚠️ 漏报 | 源码中客观存在的缺陷，模型完全未提及 |
